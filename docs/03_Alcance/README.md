# Alcance v2

Este apartado define las funcionalidades incluidas y excluidas del MVP de LemacDataLab.

## Resumen

- Aplicación móvil Android.
- Desarrollo con Jetpack Compose.
- Persistencia local.
- Arquitectura MVVM.
- Registros en cuatro ámbitos.
- Uso exclusivo de datos ficticios.
- Sin diagnósticos, tratamientos ni servicios de emergencia.
