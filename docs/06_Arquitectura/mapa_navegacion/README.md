# Mapa de navegación

Este mapa representa el recorrido principal del usuario dentro de LemacDataLab.

## Flujo principal

Inicio → Menú principal → Elegir ámbito → Nuevo registro → Historial → Detalle del registro → Editar registro.

## Navegaciones secundarias

- Menú principal → Contenidos.
- Menú principal → Recordatorios.
- Nuevo registro → Cancelar → Menú principal.
- Detalle del registro → Eliminar → Historial.
- Editar registro → Cancelar → Detalle del registro.
