# LemacDataLab

Proyecto semestral **Desarrollo de Aplicaciones Móviles**.

## Integrantes

- Marthin Celedon
- Martin Martiz

## Problemática

Actualmente, la información relacionada con neurodesarrollo, habilidades DBT, estado de ánimo y adicciones puede quedar distribuida entre diferentes herramientas y registros.

Esta fragmentación dificulta mantener la continuidad, consultar el historial y organizar las actividades pendientes de una persona usuaria.

## Objetivo general

Desarrollar una aplicación móvil que permita registrar, organizar y consultar información de autorreporte relacionada con neurodesarrollo, DBT, estado de ánimo y adicciones, utilizando únicamente datos ficticios o sintéticos.

## Funciones principales

- Registrar actividades y situaciones.
- Seleccionar el ámbito relacionado con cada registro.
- Consultar el historial.
- Revisar el detalle de un registro.
- Editar o eliminar registros propios.
- Acceder a contenidos de apoyo.
- Configurar recordatorios.

## Tecnologías consideradas

- Android Studio
- Kotlin
- Jetpack Compose
- Arquitectura MVVM
- Persistencia local
- Git y GitHub
- Figma y diagrams.net

## Estado del proyecto
